# SkyBook — Requirements

## 1. Project Overview

SkyBook is a flight booking backend application.
It allows customers to search flights, book tickets,
and manage their reservations.

## 2. Actors

- Customer
- Admin

## 3. Functional Requirements

- Create and manage flights.
- Search flights.
- Register and login.
- Create bookings.
- Process simulated payments.
- Cancel bookings.
- Send booking notifications.

## 4. Non-Functional Requirements

- Input validation.
- Secure authentication.
- Prevent duplicate seat bookings.
- Proper error handling.
- Automated testing.
- Docker deployment.

## 5. Initial Scope

Version 1 will include:
- Flight management.
- Flight search.
- Basic user management.
- Booking.
- Simulated payment.

The notification service and advanced cloud deployment
will be implemented in later phases.
